# Password Generator
Ein kleines Projekt, das ich aus Spass während der Ferien erstellt habe, um zudem meine Fähigkeiten zu präsentieren.
## Vorteile
**Sicherheit:** Nutzt das Modul ```secrets```, dass Kryptografisch sichere Passwörter generiert.
**Intuitiv einfaches interface:** Das Programm hat 2 Hauptknöpfe (generate und copy) und 4 Einstellungsknöpfe, die für die Konfiguration des ```layout_for_password``` verantwortlich sind, um zu bestimmen, ob das Passwort Grossbuchstaben (**Uppercase**), Kleinbuchstaben (**Lowercase**), Zahlen (**Numbers**) oder Symbole (**Symbols**) enthalten soll.
## Installation
Einfach die Befehle unten kopieren und im Terminal eingeben.
 
**Achtung!:** Damit die Befehle funktionieren, musst du Git installiert haben. Andernfalls kannst du einfach auf GitHub den Hauptordner herunterladen oder unter [Releases](https://github.com/niwobyte/Password-generator/releases/tag/V1.0.0) direkt ein .exe Programm installieren.
 
 ***die Befehle***
```git clone https://github.com/niwobyte/Password-generator.git```
``` cd Password-generator```
```pip install -r requirements.txt```
